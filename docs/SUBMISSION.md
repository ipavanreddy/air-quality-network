# VayuDrishti: submission pack (Track 2)

## Product description (2–3 lines)

> **VayuDrishti turns a citizen's photo into an officer's action.** Gemini checks the photo and fuses it with
> low-cost sensor, satellite and weather evidence on a 1 km grid to produce a transparent Hotspot Confidence
> score, a likely source and an evidence-grounded action brief for the right pollution-control officer. Health
> advisories reach citizens in English, Hindi and Punjabi with voice. A canonical schema with per-state
> adapters lets Delhi NCR, Punjab and Maharashtra share models and send each other cross-boundary alerts.

## Demo video script (4:45, PRD §44)

**Before recording.** Open the officer dashboard (`OFFICER_URL`) and click **Reset demo**. In live mode this
takes about 30 s because Gemini re-verifies the seeded Punjab and Maharashtra reports. Open the citizen app
(`CITIZEN_URL`) in a second window sized like a phone. Allow the microphone. Check that the header badge on both
apps reads *"N/M live · rest sample data"*.

**Recording notes.** A live Gemini photo check plus action brief takes about 10–25 s; cut the wait in the
edit. Numbers below are from a live run (they vary by a point or two). Say "likely source" and "recommended
inspection", never "polluter".

| Time | Scene (screen) | Action on screen | Voice-over (suggested) |
|---|---|---|---|
| 0:00–0:30 | **Problem.** Officer dashboard, state *Delhi NCR*, colour by PM2.5 | Hover the official station and the orange cells near Patparganj. Point at the inbox: empty | "At 3 a.m. the official station 6 km away reads *Poor*, about 112 µg/m³. Next to the industrial estate, residents breathe far worse air. The cells here score about 66 on Hotspot Confidence, just under Delhi's alert threshold of 70, so nobody is alerted. VayuDrishti closes that gap." |
| 0:30–1:10 | **Citizen report.** Citizen app | Language *हिन्दी*. Location *East Delhi (Patparganj)*, or type "Patparganj" in the Google Maps search. Pick the chimney sample photo. Tap **🎙 बोलकर बताएँ** and say "फैक्ट्री की चिमनी से काला धुआँ निकल रहा है", then stop: the text appears. **Submit** | "A resident reports in Hindi, by voice. Speech-to-Text fills in the description and the Maps Geocoding API confirms the address." |
| (result) | Citizen result card | Show: *industrial emission · severity 4/5 · confidence ~90 %*, the indicator chips, the address, *Hotspot Confidence 66 → about 80*, *Sent to the environmental officer* | "Gemini multimodal checks the photo and returns a structured verdict: event type, severity, visible indicators and confidence. A clear-sky photo would be flagged as not a pollution event. The report pushes this cell over the threshold." |
| 1:10–1:50 | **Evidence fusion.** Dashboard: new alert in the inbox (≤ 5 s). Open it | Show the Hotspot Confidence breakdown bars, then the *Evidence (observed data)* list with source + time, the wind arrow and the *Data freshness* table | "Four independent signals: the calibrated low-cost sensor anomaly (35 %), the satellite NO2 anomaly and upwind fires (25 %), the citizen report (25 %) and weather plausibility (15 %). Every value carries its source and timestamp, and low-cost sensors are labelled indicative." |
| 1:50–2:30 | **Likely source + action brief** | Scroll the *AI action brief*: summary, *Likely sources* with confidences, *Recommended inspection*, *Uncertainties*, the model/prompt version line | "Gemini writes the brief only from this evidence bundle. It must use the jurisdiction's own action rules. Any number it cites is checked against the data, and uncertainties such as station distance and satellite age are stated." |
| 2:30–3:00 | **Forecast** | Drag the forecast slider now → +24 → +48 → +72 h. The grid re-colours. Show the forecast card: range and drivers | "The shared corridor model forecasts 72 hours ahead with a range and drivers such as ventilation and upwind fires. It is backtested against persistence." |
| 3:00–3:30 | **Officer alert → action** | Tick the recommended inspection → **Acknowledge & approve selected actions** → type "Night inspection team dispatched" → **Record action** → **Close alert**. Show the audit trail | "Nothing happens without a human. The officer approves the inspection, records the action and closes the alert. Every step is in the audit trail." |
| 3:30–3:50 | **Citizen advisory with voice** | Dashboard: **Generate advisory draft** → switch English / हिन्दी / ਪੰਜਾਬੀ → **Approve & publish to citizens**. Citizen app (ਪੰਜਾਬੀ): the advisory card → **🔊 Listen** | "Gemini drafts the advisory, Cloud Translation localises it and Text-to-Speech reads it aloud in Punjabi. It is published only after approval." |
| 3:50–4:30 | **Interoperability + shared models** | Dashboard: switch state to *Punjab*. Open the crop-burning alert (seeded sample report + ~40 satellite fire detections upwind) → **Acknowledge** → **Send cross-boundary alert to Delhi NCR**. Switch back to *Delhi NCR*: the incoming cross-boundary alert. Open the *Shared model registry*: `igp-smog-forecast-v1` used by Delhi NCR and Punjab, MAE vs persistence. Switch to *Maharashtra*: construction-dust hotspot, threshold 65, persistence model | "Punjab's sensor feed uses different field names and time formats, and its adapter maps them to the same canonical schema. A stubble-fire hotspot upwind of Delhi becomes an approved cross-boundary alert. Both states reuse one registered model with its own fine-tune. Maharashtra has a different threshold and model, with no code change." |
| 4:30–4:45 | **Scale and deployment** | Show the header badge breakdown (live Gemini, Translation, TTS, STT, Maps, BigQuery, GCS), then the README architecture diagram | "One street, one ward, one city, one corridor. It runs on Cloud Run and Vercel, stores to BigQuery and Cloud Storage, and onboarding a new state is a JSON adapter. That works for any Indian district from day one with Earth Engine, and across borders too." |
